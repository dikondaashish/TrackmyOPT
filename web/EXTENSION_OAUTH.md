# Extension OAuth Flow

Complete implementation of the Chrome extension authentication flow with OPT signup.

## 🔄 Authentication Flow

### Overview
```
Extension → Web Auth Page → Google/Manual Auth → Callback → Extension
```

### Detailed Steps

1. **Extension Initiates Auth**
   ```javascript
   const redirectUri = chrome.identity.getRedirectURL();
   const state = generateRandomState();
   const authUrl = `https://your-site.com/auth/extension?redirect_uri=${redirectUri}&state=${state}`;
   
   chrome.identity.launchWebAuthFlow({
     url: authUrl,
     interactive: true
   }, (responseUrl) => {
     // Extract token from fragment
   });
   ```

2. **User Lands on Auth Page**
   - URL: `/auth/extension?redirect_uri=...&state=...`
   - Validates `redirect_uri` and `state` are present
   - Shows error if missing

3. **User Chooses Auth Method**
   
   **Option A: Sign in with Google**
   - Clicks "Continue with Google"
   - Redirects to Google OAuth
   - Google redirects to Supabase
   - Supabase redirects to `/auth/extension/callback?redirect_uri=...&state=...`
   
   **Option B: Manual Sign In**
   - Enters email and password
   - Calls `supabase.auth.signInWithPassword()`
   - Redirects to `/auth/extension/callback?redirect_uri=...&state=...`
   
   **Option C: Manual Sign Up**
   - Fills form: firstName, lastName, email, password
   - Fills OPT dates: program end, DSO date, OPT start/end, STEM dates
   - Checks "I'm STEM-eligible" if applicable
   - Calls `supabase.auth.signUp()`
   - Inserts into `profiles` table
   - Inserts into `opt_status` table
   - Redirects to `/auth/extension/callback?redirect_uri=...&state=...`

4. **Callback Handler Processes Auth**
   - Server-side route: `/auth/extension/callback/route.ts`
   - Validates session using `@supabase/ssr`
   - Mints JWT token (10-minute expiry)
   - Returns HTML page with auto-redirect

5. **HTML Page Redirects to Extension**
   ```javascript
   const url = `${redirect_uri}#id_token=${idToken}&state=${state}`;
   window.location.href = url;
   ```
   
6. **Extension Receives Token**
   - `chrome.identity.launchWebAuthFlow` captures the URL
   - Extracts `id_token` from fragment
   - Verifies `state` matches
   - Stores token for API calls

## 🔐 Security

### JWT Token
- **Algorithm**: HS256
- **Expiry**: 10 minutes
- **Payload**:
  ```json
  {
    "userId": "uuid",
    "email": "user@example.com",
    "iat": 1234567890,
    "exp": 1234568490,
    "iss": "trackmyopt-web",
    "aud": "trackmyopt-extension"
  }
  ```

### State Parameter
- Random string generated by extension
- Passed through entire flow
- Validated on return to prevent CSRF

### Redirect URI
- Chrome extension redirect URL
- Format: `https://<extension-id>.chromiumapp.org/`
- Validated to ensure it's from extension

## 🐛 Troubleshooting

### "Missing required parameters" error
- Ensure URL includes `?redirect_uri=...&state=...`
- Both parameters are required

### "Authentication failed" after Google OAuth
- Check Supabase dashboard for Google provider settings
- Verify callback URL is correct
- Check browser console for errors

### "Failed to create profile" error
- Verify database migration ran successfully
- Check RLS policies allow INSERT for authenticated users
- Look at Supabase logs for detailed error

### Date format errors
- Dates must be in MM/DD/YYYY format
- Example: `05/15/2024`
- Will be converted to YYYY-MM-DD for database

### Token not captured in extension
- Ensure token is in URL fragment (`#id_token=...`)
- Check `chrome.identity.launchWebAuthFlow` implementation
- Verify redirect URI matches extension ID

## 📚 Implementation in Extension

### Example Extension Code

```javascript
// extension/src/auth.ts
const WEBSITE_URL = 'https://your-site.com';

async function authenticateUser() {
  const redirectUri = chrome.identity.getRedirectURL();
  const state = generateRandomState();
  
  const authUrl = `${WEBSITE_URL}/auth/extension?redirect_uri=${encodeURIComponent(redirectUri)}&state=${encodeURIComponent(state)}`;
  
  return new Promise((resolve, reject) => {
    chrome.identity.launchWebAuthFlow(
      {
        url: authUrl,
        interactive: true
      },
      (responseUrl) => {
        if (chrome.runtime.lastError) {
          reject(chrome.runtime.lastError);
          return;
        }
        
        // Extract token from fragment
        const url = new URL(responseUrl);
        const fragment = url.hash.substring(1); // Remove #
        const params = new URLSearchParams(fragment);
        
        const idToken = params.get('id_token');
        const returnedState = params.get('state');
        
        if (returnedState !== state) {
          reject(new Error('State mismatch'));
          return;
        }
        
        if (!idToken) {
          reject(new Error('No token received'));
          return;
        }
        
        // Store token
        chrome.storage.local.set({ auth_token: idToken }, () => {
          resolve(idToken);
        });
      }
    );
  });
}

function generateRandomState() {
  const array = new Uint8Array(32);
  crypto.getRandomValues(array);
  return Array.from(array, byte => byte.toString(16).padStart(2, '0')).join('');
}
```
