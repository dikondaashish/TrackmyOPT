%  Single-column, ATS-safe resume template with a bolder accent treatment for
%  product / design-adjacent engineering roles.
%
%  NOTE: this template is deliberately NOT two-column. Two-column resumes are
%  reordered or dropped by Workday/Greenhouse/Taleo parsers. Visual character
%  here comes from typography and accent rules, never from layout geometry.
%
%  CONTRACT (do not break):
%   * Self-contained. Uses only core TeX Live packages so the file compiles
%     standalone on the remote compiler (no project-local .sty is uploaded).
%   * Single column. No tabular, no multicol, no images, no text boxes.
%   * Section order is fixed:
%       Contact -> Summary -> Skills -> Experience -> Projects -> Education
%       -> Certifications
%   * Body text 10pt, margins 0.65in, Helvetica-class sans face.
%==============================================================================
