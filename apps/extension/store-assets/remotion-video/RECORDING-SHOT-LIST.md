# Recordly shot list

Aim for separate 20–30 second takes, with two seconds of stillness before and three seconds after each interaction. Long AI operations may need longer takes; retain the original timing so the edited version can clearly indicate a skipped wait. Use a fictional demo account and safe demo application pages. No customer records or real password capture.

Start with **prefill.mp4**, then résumé preparation and tracking. Record the remaining scenes once the first edit establishes the style.

| Export filename     | Feature               | What to record                                                                                                            |
| ------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| profile.mp4         | Application profile   | Open Your application profile; show fictional contact, experience and education records.                                  |
| prefill.mp4         | Smart Prefill         | Show empty supported contact fields, click Prefill, pause on result; show a pre-entered field remains unchanged.          |
| resume.mp4          | Tailored résumés      | Open a demo job, choose source resume, generate or show a previously generated tailored result, review it.                |
| templates.mp4       | Résumé templates      | Open the real template selector; show its six options, then preview one. Do not imply six outputs were generated.         |
| job-fit.mp4         | Job-fit analysis      | Show actual job-fit analysis for the fictional resume; pause at relevant skills and a gap.                                |
| answers.mp4         | Screening answers     | Show one supported screening question, generate or reuse a genuine draft, then review the marked answer.                  |
| cover-letter.mp4    | Cover letters         | Show the actual cover-letter control and its draft review panel.                                                          |
| tracker.mp4         | Job tracker           | Save a fictional/demo opportunity with Add this job to tracker; inspect role/company before confirming.                   |
| continuous.mp4      | Continuous Prefill    | Show enabled Continuous mode on an eligible plan; manually move to a supported step and show reused answers.              |
| autopilot.mp4       | Guided Autopilot      | Enable Guided Autopilot in a safe demo application; record supported progression and a visible review stop. Never submit. |
| private-answers.mp4 | Saved private answers | Demonstrate a fictional work-authorization response on a demo form; avoid any actual private profile values.              |
| portal-login.mp4    | Portal login prefill  | Use an HTTPS demo login form with fictional credentials; show password masked and Sign in unpressed.                      |
| opt.mp4             | OPT tools             | Show actual OPT Apply Date and OPT Clock with explicitly fictional records. Keep DSO context visible.                     |
| stem.mp4            | STEM OPT tools        | Show STEM Apply Date and STEM Clock using fictional dates; include earlier OPT employment history.                        |

Export to `public/recordings/` inside the Remotion project. Avoid notifications, unrelated tabs, personal account menus, and actual application submissions. Passwords must stay masked. Keep real consent/review steps visible and do not accelerate the result so it implies instant AI generation.

The timeline currently allocates eight seconds per feature. This is a starting edit, not a demand to complete the real workflow in eight seconds. Change duration and trim after reviewing each take.
