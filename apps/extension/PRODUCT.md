# Extension product context

## Register

product

## Users and purpose

TrackMyOPT students check OPT/STEM filing dates and employment timelines in a small Chrome popup while using the website. The popup should support a quick date entry or status check and use the same identity as the dashboard.

## Direction

The user requested minimal visible text, question-mark help on hover, consistent colors and controls, and the original GIF logo. Preserve the website's familiar palette and existing light/dark preferences. Avoid large explanatory panels, repeated instructions, and decorative gradients on every action.

## Interaction principles

Keep labels, dates, actions, and actionable status visible. Put supporting rules and optional-field explanations in help that works with mouse, keyboard, and click. Preserve calculation and save behavior. Use readable contrast, visible focus, and reduced-motion support.
