### Email 2: "Form 8843 vs 1040-NR: Which Do I File?" (Day 2)
**Subject Line:** "Form 8843 vs 1040-NR: Don't File Wrong (Decision Tree Inside)"

```
Subject: Form 8843 vs 1040-NR: Don't File Wrong (Decision Tree Inside)

Hi [First Name],

Most F-1/OPT students file the WRONG forms and don't even know it.

Let me clear this up.

---

**Form 8843: Information Return of Non-Resident Alien**

What it is: Not a tax return. It's an IRS informational form.

Who files it: Every F-1 and J-1 visa holder in the US (even if no income)

What it covers: Your visa status, exempt income, days in US

When to file: April 15 (or June 15 if outside US)

Result: Usually $0 tax owed (informational only)

**Form 1040-NR: US Individual Income Tax Return (Non-Resident Alien)**

What it is: A tax return (you calculate taxes owed).

Who files it: Non-resident aliens who earned US income

What it covers: Wages, taxes withheld, deductions, calculated tax

When to file: April 15, 2026

Result: Usually a refund (because too much was withheld)

---

**DECISION TREE:**

Did you earn US source income in 2025?
- YES → File 1040-NR + File 8843 (BOTH)
- NO → File 8843 only

(Note: "income" = salary, wages, side gigs. NOT financial aid, not scholarships.)

Most F-1/OPT students earn income, so most need to file BOTH.

---

**COMMON MISTAKES:**

❌ Filing only 8843 (but you earned income)
❌ Filing 1040 instead of 1040-NR (wrong form)
❌ Trying to use TurboTax (doesn't support 1040-NR — it will reject you)

✅ CORRECT: File 1040-NR (for income) + 8843 (for visa status)

---

**HOW TO FILE:**

Option 1: Use Sprintax or Glacier Tax Prep (designed for non-resident aliens)
Option 2: Hire a CPA who knows F-1 taxes
Option 3: DIY with 1040-NR instructions (harder, but possible)

Cost:
- Sprintax: $50-100 (software does it for you)
- CPA: $200-400 (professional does it)
- DIY: $0 (but risky)
```
