## 🚀 Task 5: SEO & Distribution Strategy

### On-Page SEO Checklist (for every article)
- [ ] Title tag (50-60 chars, keyword-rich, engaging)
- [ ] Meta description (150-160 chars, include CTA)
- [ ] H1 title (matches or closely mirrors title tag)
- [ ] Keyword in first 100 words
- [ ] H2/H3 hierarchy (proper structure for AI)
- [ ] Internal links (minimum 3, target relevance)
- [ ] External links (minimum 2, authoritative sources)
- [ ] Featured image with descriptive alt text
- [ ] FAQ schema (5-8 Q&A pairs)
- [ ] HowTo schema (where procedural)
- [ ] Word count: 2,000–4,000 words
- [ ] Key Takeaway box (AI-quotable summary)
- [ ] Table or list (structured data for AI models)
- [ ] CTA (to tool, email signup, or upgrade)
- [ ] Open Graph image (1200x630px)

   - Day 5: Reminder email (for non-openers)

   - Reddit: Helpful comments + article link (context-relevant subreddits)

3. **Community Channels:**
