## Quick Start (5 minutes)

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Click **"Add property"** → Select **"URL prefix"**
3. Enter: `https://trackmyopt.com`
4. Choose **verification method**:
   - **HTML file** (easiest) - Upload file to /public
   - **HTML tag** - Add meta tag to layout.tsx
   - **Google Analytics** - Link existing GA account
   - **Google Tag Manager** - Use GTM container

## Detailed Setup Steps

### Step 1: Create GSC Property

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Sign in with your Google account (must be organization account)
3. Click **"Add property"**
4. Select **"URL prefix"** property type
5. Enter: `https://trackmyopt.com`
6. Click **"Continue"**

### Step 2: Verify Domain Ownership

**Option A: HTML File (Recommended)**
1. Download the verification file from GSC (e.g., `google12345abc.html`)
2. Save to `/public/google12345abc.html`
3. File will be accessible at: `https://trackmyopt.com/google12345abc.html`
4. Click **"Verify"** in GSC
5. GSC will fetch and confirm file exists

**Option B: HTML Meta Tag**
```html
<!-- Add to app/layout.tsx <head> -->
<meta name="google-site-verification" content="YOUR_VERIFICATION_CODE_HERE" />
```

### Step 3: Access Search Console

After verification, you'll see:
- **Coverage** - Indexed vs. errors
- **Sitemaps** - Submit sitemap.xml
- **Core Web Vitals** - Performance metrics
- **Links** - Referring domains
- **Mobile Usability** - Mobile compatibility
- **Search Performance** - Click data
- **Rich Results** - Schema validation

### Step 4: Submit Sitemaps

1. Go to **Sitemaps** in GSC left menu
2. Click **"Add/test sitemap"**
3. Enter: `sitemap.xml`
4. Click **"Submit"**

Sitemap locations:
- `/public/sitemap.xml` - Main sitemap
- Auto-generated by Next.js during build

### Step 5: Configure Indexation

1. Go to **Settings** → **Crawl stats**
2. Review:
   - Requests per day
   - Crawl time
   - Kilobytes downloaded

Settings to verify:
- **Crawl rate** - Auto (or "Let Google optimize")
- **User agent Allow** - Yes, allow Googlebot
- **Standard results** - Include all URLs

### Step 6: Monitor Coverage

#### What to expect:
- **Indexed** (Good) - Pages indexed by Google
- **Discovered not indexed** (Watch) - Found but not yet indexed
- **Excluded** - Intentionally not indexed (sitemap, robots.txt, etc.)
- **Errors** - Crawl or indexing errors

#### Key metrics to track:
- Total URLs in sitemap
- % of URLs indexed
- Any 404s or crawl errors
- Mobile usability issues

## Common Issues & Solutions

### Issue: "Couldn't fetch your page"
**Cause**: robots.txt blocking Googlebot or page inaccessible
**Solution**: 
```
# In public/robots.txt
User-agent: Googlebot
Allow: /
```

### Issue: "Page has no title tag"
**Solution**: All pages have title tags via metadata - verify:
```typescript
export const metadata: Metadata = {
  title: "Page Title",
};
```

### Issue: "Declared as noindex"
**Solution**: Don't set noindex in robots meta tags:
```typescript
// ✅ Good (default)
robots: {
  index: true,
  follow: true,
}

// ❌ Bad (blocks indexing)
robots: {
  index: false,
}
```

### Issue: "Mobile usability errors"
**Solution**: Validate with [Mobile-Friendly Test](https://search.google.com/mobile-friendly/)

## Alerting Configuration

### Email Alerts (Recommended)
GSC sends alerts for:
- ⚠️ Mobile usability issues
- ⚠️ Security issues (malware, hacking)
- ⚠️ Indexing issues
- ℹ️ News coverage

Enable in **Settings** → **Email notifications**

### Custom Alerts (via API)
Monitor via webhook integration:
```
POST https://trackmyopt.com/api/gsc-alerts
{
  "issue_type": "mobile_usability",
  "severity": "critical",
  "affected_url": "https://trackmyopt.com/blog/..."
}
```
