# Marketing Claims Evidence Register

Last verified: 2026-08-27

This register is the source of truth for measurable public claims. It uses
aggregate production data only; do not add personal information to this file.

## Current supported claim

**“2,500+ registered users”** is supported by the production Supabase Auth
database as of the verification date:

- 2,580 non-anonymous, non-deleted registered users
- 2,537 users with confirmed email addresses
- 2,038 application profiles
- 657 users signed in during the preceding 30 days

The product does not have reliable evidence that every account holder is an
F-1 student, that a user was “helped,” or that the product is ranked number
one. Public copy must not make those claims.

## Required review

Recheck this aggregate query at least monthly and before any campaign that
uses a numerical claim. Claims about job outcomes, testimonials, universities,
or attorney outcomes require separate written evidence and consent.
